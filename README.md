# Atualizações do MarmorariaSystem

Canal de distribuição de instaladores do MarmorariaSystem para Windows x64.
Os instaladores e as somas SHA-256 ficam em Releases. Este repositório não
contém o código-fonte, bancos de dados ou configurações das empresas.

Faça backup antes de atualizar e feche o Desktop em todas as estações.
Instale na mesma pasta. Máquinas já configuradas não precisam refazer a
configuração de servidor/estação ao concluir o instalador.

O instalador não inclui uma licença de uso do sistema. Acesso e ativação
continuam sujeitos à licença de cada instalação.
